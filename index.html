✨ 功能特性

🔒 端到端加密

Ed25519身份密钥 + X25519密钥交换，消息仅收发双方可解密。服务器只存储密文，无法读取内容。

🗄️ 双模式私钥存储

可选择将私钥加密存放于服务器（多设备登录），或完全本地存储，私钥永不离开本机。

🛡️ 指纹验证 & 信任管理

通过公钥哈希（指纹）验证好友身份，防止中间人攻击。信任数据库本地加密保存。

📨 离线消息队列

好友离线时自动缓存消息，上线后立即送达，不错过任何重要对话。

🚦 DoS & 封禁防护

IP注册/登录限流，自动/手动封禁恶意用户，管理员可操作邀请码及黑白名单。

🖥️ 跨平台 GUI

基于 tkinter 的图形界面，支持系统托盘、消息提醒，开箱即用。

🔐 加密协议细节
组件算法用途
身份密钥Ed25519数字签名，验证消息发送者身份
密钥交换X25519 (ECDH)协商临时共享密钥
对称加密 + 认证AES-256-GCM消息加密和完整性校验
密钥派生HKDF-SHA256从 ECDH 共享密钥派生 AES key 与 nonce
密码存储PBKDF2-SHA256 (600k 迭代)服务端存储密码哈希，有效抵抗暴力攻击

📬 消息加密流程: 临时X25519密钥对 → ECDH交换 → HKDF派生密钥 → AES-256-GCM加密 → Ed25519签名 → 接收方验证签名并解密。

📦 安装与运行

环境依赖

  • Python 3.8+
  • cryptography , pystray , Pillow
pip install cryptography pystray Pillow

🚀 启动服务器

python server.py

首次启动需要设置管理员密码，用于保护服务器密钥（自动生成在 server_keys/）。

💬 启动客户端

python client.py

默认连接 127.0.0.1:5555，可手动修改服务器地址。注册、登录后即可与在线用户端到端加密通信。

🛠️ 管理员命令 (admin.py)

# 生成邀请码
python admin.py invites add --count 5 --uses 1 --length 8

# 设定注册需要邀请码
python admin.py invites set-require true

# 封禁IP / 用户
python admin.py ban ip 192.168.1.10 --duration 3600
python admin.py ban user alice
python admin.py list-bans

🔏 安全信任模型

🆔 服务器指纹

客户端首次连接时核对服务器Ed25519指纹，并存入本地信任库。若指纹变更会发出MITM警告。

👥 用户指纹验证

双方通信之前可通过安全渠道（当面/电话）比对指纹，一旦信任，后续消息自动解密显示。

🔐 本地信任库防篡改

信任记录使用HMAC-SHA256完整性保护，防止恶意篡改。
